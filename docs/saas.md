# 企业工作区

从 [企业入口](http://127.0.0.1:8000/#account) 选择「创建企业账号」，填写企业名称、姓名、登录名和密码。首位成员成为管理员。已有账号可加入多家企业；点击当前企业名称即可切换。企业名称是登记名称，系统不验证企业工商身份。

| 成员 | 可操作范围 |
| --- | --- |
| 员工 | 提交资料，查看本人任务进度、原件与人工验收决定 |
| 审计人员 | 查看本企业任务与底稿，对照原页、留痕更正、签收和导出 |
| 管理员 | 具备审计权限，另可邀请、移除成员或调整角色，查看成员操作记录 |

管理员从「企业成员」生成一次性邀请链接并直接交给受邀人。链接有效期 72 小时，可撤销。企业签收和核图在服务端记录已登录账户、当时姓名以及对应版本。移除或降权即影响之后的访问和审计写入。

## 本地运行

现有服务保留原来的单机台账。企业台账使用独立的企业编号；企业成员只能在获得授权的空间内操作。已有本机案例归属于本机工作区。下列命令另起一个仅开放企业入口的实例，使用独立的持久化资料目录。

```sh
AUDIT_ACCESS_MODE=saas AUDIT_DATA_DIR="$PWD/server/data/enterprise" \
  PORT=8010 server/.venv/bin/python server/main.py
```

打开 [企业实例](http://127.0.0.1:8010/)。实例使用一个 Waitress 进程、一个持久化任务 worker 和 SQLite WAL。账户、成员、会话和证据索引存于数据库，原件与页图位于同一数据目录。业务接口的企业编号同时约束原件、底稿、证据包、历史票号和任务重试。整目录备份应包含数据库和原件。

对公网部署时，使用独立资料目录，设置 `AUDIT_ACCESS_MODE=saas` 及 `AUDIT_PUBLIC_ORIGIN=https://实际域名`。在前置反向代理终止 TLS、保留 Host，并将流量转发到回环地址。该模式关闭本机匿名台账，HTTPS 来源使用 Secure 会话 cookie。原件进入模型服务的处理路径见[使用说明](README.md)。

## 验收

```sh
PYTHONPATH=server server/.venv/bin/python -m unittest discover -s server/tests -q
node frontend/tests/workspace.mjs
```

浏览器测试使用独立临时目录和 Chrome，覆盖注册、双企业切换、员工邀请及手机上传界面。可通过 `CHROME_BIN` 指定 Chrome 可执行文件。在本机生成演练资料后增加 `--live`，可用服务端密钥将带「合成演练」标识的采购合订件走完上传、模型处理与审计员读底稿流程。
