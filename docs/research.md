# 财会推理与证据验证

FinQA 以附带可执行程序的金融问题检验数字推理，TAT-QA 研究从财务表格与正文取数后执行运算。我们据此将程序、取数及金额结果一起写入底稿，每个操作数单独绑定单据、金额字段、币种、单位和原文引用。[FinQA](https://aclanthology.org/2021.emnlp-main.300/) · [TAT-QA](https://aclanthology.org/2021.acl-long.254/)

FinRAGBench-V 研究金融文档图像问答的证据定位。本项目的复核界面保留整张模型输入页；有可信文字层时标记原文区域。对于初读遗漏的印刷标题，服务端可将有唯一页内定位的已知单据标题交给独立视觉复检。标题文字、位置、输入候选及可读确认都能在底稿中核对。缺标题、复检冲突、扫描覆盖层或一页多个候选均保留人工核验入口。[FinRAGBench-V](https://aclanthology.org/2025.emnlp-main.211/)

## 查看与重算

在新版本底稿展开「查看金额算式与取数依据」。采购可核对发票价税差额、合同与发票及验收差额，以及多票汇总。差旅可核对凭证合计与申请差额。每个数值均能打开原件所在页与对应引文。系统用十进制定点金额精确到分，当前计算覆盖非负人民币元；红字方向、单位冲突及缺少关键事实时转为人工核验。

证据包的 `report.json` 包含 `policy.calculations` 和每项程序的 `calculations`。`python3 server/verify.py 包名.zip` 从图关系和引文重建算式，检查数字的单据归属、字段角色、币种、单位与算式结果，也会发现同金额取错单据的情况。原有底稿保留生成当时的方法与摘要。

## 合成演练回放

```sh
server/.venv/bin/python docs/samples/replay.py
```

脚本以只读方式打开指定演练组，重用已存证的真实模型读取和模拟人工更正，按当前程序计算。2026-11-23 的七案回放核对了 18 条算式、46 个操作数。三单相符、价税差 2,000 元、差旅超报 150 元、分票汇总、模糊扫描、同票重提及合订三单均符合预期。模糊扫描生成零条金额算式。演练规模与资料来源限定了这些结果的适用范围。

对于当前规则版本，可以进一步从归档图谱离线重跑全部确定性检查、专家选择的追加程序及总建议。使用 `server/.venv/bin/python server/verify.py --rules 证据包.zip`。校验器先比对本机程序摘要，只运行本机代码。该模式适合独立复核；历史版本需要对应版本的可信检出。原件真伪和银行实际清算需要另行取得证据。

加入付款回单两案后，`server/.venv/bin/python docs/samples/replay.py --bank-run-id synthetic-bank-v1` 在本机九案上复现了 20 条算式、50 个带原件引用的操作数。核图更正与模型原始读数可在各版底稿中分别审阅。
