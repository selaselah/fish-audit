## 配色验收

桌面和手机在实际浏览器中读取前景、底色，按 sRGB 相对亮度计算对比度。首页三份原件的读数、当前文件页签、企业登录按钮、台账主按钮和定位引文的状态标签纳入浏览器回归。手机原件入口的点击范围、系统强制颜色模式下选中页签的双下划线也一并检查。[浏览器回归](../../frontend/tests/product.mjs) · [配色依据与 W3C 来源](../../3rd/interface-color.md)

| 文字所在位置 | 文字与底色对比度 |
| --- | --- |
| 首页「进入工作台」、台账「新建审计」、企业登录按钮的白字 | 6.65∶1 |
| 白底石墨色正文、白底次要说明 | 15.46∶1、5.77∶1 |
| 已相符、待核风险、已知问题的文字与各自淡底 | 6.60∶1、6.49∶1、6.23∶1 |
| 待复核任务状态标签的紫字与淡紫底 | 6.74∶1 |

axe-core 对图案背景和手机弹窗中的部分引文报告需要补查。取首页与企业登录页网格截图中的最深交点，以较浅的说明文字计算，分别为 6.40∶1、6.39∶1。另把手机核图窗口中待补查的 39 个文本元素逐一滚入视野，读取前景及其最近的不透明底色，最低为 5.77∶1。
